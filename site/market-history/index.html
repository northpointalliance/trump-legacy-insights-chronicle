Historic Market Reference (2017–2021)

Event-level market reactions during Donald Trump's first presidency, Dow Jones Industrial Average, U.S. Dollar Index, and 10-year Treasury yield.

What does this reference page cover?

This page archives first-term (2017–2021) market moves tied to major presidential actions. It uses the same indices and before/after methodology as the original site build. For second-term quarterly data (Q2 2025–Q1 2026), see the Markets section on the home page.

Figures show session or next-session changes around each event date. Percent changes are rounded; Treasury moves are in basis points (bp).

How did markets react to key first-term decisions?

Financial markets responded to major Trump administration actions with measurable shifts in the Dow Jones Industrial Average, the U.S. Dollar Index (DXY), and the 10-year Treasury yield. The table lists before-and-after levels and percent changes for five documented events.

How was this data compiled?

Each row pairs a documented first-term policy event with market levels immediately before and after the event window, using the same three benchmarks as the original chronicle build:

  • Dow Jones Industrial Average: closing levels (S&P Dow Jones Indices)
  • U.S. Dollar Index (DXY): ICE U.S. Dollar Index
  • 10-year Treasury yield: U.S. Treasury constant maturity, via FRED DGS10
